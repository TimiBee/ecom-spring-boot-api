# E-Commerce Backend API

Welcome to the **E-Commerce Backend API** project! This API is designed to provide a robust, scalable backend for an e-commerce platform. It includes features like user authentication, product management, and order processing, all built using **Spring Boot**, **Java**, and **PostgreSQL**.

## Features

- **User Authentication**: Secure login and registration with JWT-based authentication
- **Role-Based Access Control**: Admins and users have different permissions
- **Product Management**: Admins can add, update, and delete products
- **Order Processing**: Users can place and manage orders
- **Swagger API Documentation**: Automatic API documentation for easy access and testing
- **PostgreSQL Integration**: All data is stored securely in a PostgreSQL database

## Tech Stack

- **Backend Framework**: [Spring Boot](https://spring.io/projects/spring-boot)
- **Programming Language**: Java
- **Database**: [PostgreSQL](https://www.postgresql.org/)
- **Security**: JWT Authentication
- **Persistence**: [JPA](https://spring.io/projects/spring-data-jpa) and [Hibernate](https://hibernate.org/)
- **API Documentation**: [Swagger](https://swagger.io/)
- **Build Tool**: [Maven](https://maven.apache.org/)
- **Version Control**: Git, GitHub
